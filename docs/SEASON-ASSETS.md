# ORIGEN — Seasonal asset mapping

The UI expects four seasonal hero assets so desktop/mobile can use the composed references supplied for this iteration.

- `assets/images/origen_panoramic_summer_16x9.jpg`
- `assets/images/origen_panoramic_summer_9x16.jpg`
- `assets/images/origen_panoramic_winter_16x9.jpg`
- `assets/images/origen_panoramic_winter_9x16.jpg`

Current repo already contains the winter visual family as PNG references; this document defines the normalized runtime filenames used by the season controller.

The selector is present in the 3D intro, desktop landing header and mobile menu. Season choice is persisted locally and drives the landing hero plus 3D atmosphere.
